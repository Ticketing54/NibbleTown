**프로젝트 소개**: 
낮에는 정비하고, 밤에는 몰려오는 몬스터로부터 마을을 방어하는 타운 디펜스 액션게임.
CluadeCode + MCP for Unity 를 사용하여 개발

**개발 기간** : 2026.05.07 ~ 현재

**플랫폼**:  PC (Mobile 확장 고려)

**사용 기술** : Unity 6.3LTS, C#, ClaudeCode, MCP for Unity

**핵심 목표** :

- ScriptableObject기반 데이터 관리로 기획 변경에 유연한 구조 구축
- 인터페이스 기반 구조를 활용하여 확장성과 유지보수성을 고려한 시스템 개발
- ClaudeCode 로 간단한 작업이나 반복작업을 AI 로 가속, 아키텍쳐 결정은 직접 판단 후 적용
- 단 시간 내에 프로토 타입 완성
